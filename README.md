# 3D 바이브 코딩 (3D Vibe Coding) 핸드북

> 한 줄의 프롬프트에서 실제로 실행 가능한 장면까지: GPT-6 Astra × Tripo 전체 워크플로우 실전 테스트

코딩을 전혀 할 줄 모르는 비개발자가 AI를 활용해 3D 에셋을 생성하고, 이를 실제로 동작하는 프로젝트에 연결하는 방법.
386페이지, 25.6만 자, 260장의 이미지, 6개의 플레이 가능한 데모. 모든 수치는 검증 가능하며 실패했던 과정도 그대로 기록되어 있습니다.

현재 버전: **v260914c** (2026-09-14)

**저자**: 화수(花叔 / AI Native Coder) · 이 책은 직접 차를 몰고 둘러볼 수 있는 파리 도시를 만들며 기록한 실전 제작기입니다.

## 어디부터 읽어야 할까요?

| 사용자의 상황 | 이동할 챕터 |
|---|---|
| 이미지-to-3D 생성을 처음 사용하며, 한 번 전체 과정을 돌려보고 싶은 경우 | §01 10분 만에 끝내는 첫 이미지-to-3D |
| 모델은 생성되었으나, 다음 단계를 어떻게 진행해야 할지 모를 때 | §03 생성 그 이후 |
| 폴리곤 수가 너무 많아 면 리덕션(감면)을 하고 싶을 때 | §04 면 리덕션 및 리토폴로지 |
| 캐릭터에 뼈대를 심고 움직이게 하고 싶을 때 | §06 리깅과 애니메이션 |
| 크레딧/포인트가 부족할 때 | §07 크레딧을 가장 효율적으로 쓰는 방법 |
| **이미 작업을 시작했으나 특정 문제/증상에 막혔을 때** | **부록 B 트러블슈팅 색인**, 증상별 5개 대조표 참조 |

## 저장소 구성

```
book/        핸드북 HTML 버전 + 260장 이미지
demos/       3개 데모의 소스 코드 (GLB 모델은 리소스 패키지로 제공되며 코드는 여기서 바로 확인 가능)
scripts/     11개 유틸리티 스크립트: 면 리덕션 한계, 일괄 파이프라인, GLB 분석 및 렌더링
manifest/    에셋별 상세 목록, 배포 패키지 인덱스
```

## 3D 모델 에셋에 대하여

본 저장소의 모든 3D 에셋은 저자(화수)가 개인 Tripo 크레딧을 소비하여 직접 생성했습니다. 각 에셋의 상세 스펙(트라이앵글 수, 버텍스 수, 텍스처 해상도, 용량, 생성 파라미터, 소모 크레딧)은 핸드북 부록 A에 기재되어 있습니다.
